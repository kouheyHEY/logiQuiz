# ジャソケソバトラー v0.2.0 Prototype

## Short description

ヒントを読み、嘘を見抜く。あいこでもライフが減る心理戦じゃんけんカードバトル。

## Description / 説明

相手の一言はヒントか、それとも嘘か。

ジャソケソバトラーは、相手の特徴と発言から次の手を読み、カードを選んで勝ち抜く短時間のブラウザーゲームです。グー・チョキ・パーは何度でも使用できますが、あいこでもライフを0.5失います。

### v0.2.0 Prototype

- グーだけを出す最初の相手が操作を案内
- 特徴と発言が異なる通常敵
- 3〜5人ごとに現れる強敵
- 嘘をつく敵を含む心理戦
- 強敵撃破でライフ0.5回復
- 強敵を倒すと無敵の使い切りカード「グチョパ」を獲得
- WIN・LOSE・AIKOとハート変化の演出
- スマートフォンのタップ操作に対応

操作：出したいカードをタップまたはクリックしてください。

プレイ時間の目安：1プレイ数分。無料でブラウザーから遊べます。
