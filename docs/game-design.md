# ゲーム設計

## 初期状態

- プレイヤーは「グー」「チョキ」「パー」をすべて無制限に使用できる。
- カードは枚数ではなく「使用不可（0）」または「無制限（∞）」で管理する。
- ライフは2から開始し、2つのハートで表示する。
- 0.5ライフは半分塗られたハートで表現する。
- 制限時間は設けない。

## 通常戦

1. プレイヤーと相手がカードを1枚ずつ出す。
2. 両者のカードをオープンし、じゃんけんのルールで勝敗を決める。
3. 結果に応じて以下を処理する。
   - あいこ: ライフを0.5失い、ライフが残っていれば同じ相手との対戦を続ける。
   - 勝利: 次の相手との対戦へ進む。
   - 敗北: ライフを1失う。
- プレイヤーと敵のカードは勝負後も消費されない。
- 強敵を1体撃破するたびに、通常のすべての手に勝つプレイヤー専用カード「グチョパ」を1枚取得する。
- 強敵を撃破するとライフを0.5回復する。ただし最大ライフ2を超えず、ゲームオーバー後の復活には使用しない。
- グチョパは取得後、プレイヤーカード群の一番右へ追加し、使用すると1枚消費する。
- グチョパのカードとバトル表示には `hand-metal` アイコンを使用する。
- リトライで進行をリセットした場合、グチョパは未取得へ戻す。

### 勝負演出

1. プレイヤーがカードを選ぶ。
2. プレイヤーのカードと、裏向きの相手カードが場に出る。
3. 相手カードをめくり、両者の手を公開する。
4. 勝利・敗北・あいこを表示する。
5. 演出の完了後に次のターンへ進む。
- 演出中はカードを再選択できない。
- OSでモーション軽減が指定されている場合は、演出時間を短縮する。
- 勝利と敗北は画面中央へ控えめな大きさで `WIN` / `LOSE` と表示し、短い拡縮とフェードで消す。
- あいこは短い画面シェイクの後、画面中央へ大きな `AIKO` とカブトムシアイコンを表示する。
- 敗北時は `−1`、あいこ時は `−0.5` をハートのそばへ表示し、ハートを短く揺らしてライフ変化を伝える。
- 勝利時にライフは回復しない。

## 敵の特徴と発言

- 画面上部に敵の名前、特徴、使用可能なカードを表示する。
- 敵側のカードはプレイヤー側と同じカードUIを使い、並びとアイコンの向きを反転して向かい合わせにする。
- 敵はプレイヤーがカードを選ぶ前に一言発する。
- 発言は次の手のヒントになるが、性格によっては心理戦や嘘を含む。
- 敵のカードも「使用不可（0）」または「無制限（∞）」で管理し、使用しても減らない。

### 最初の相手

- 最初の相手はチュートリアル専用とし、必ずグーだけを出す。
- 特徴と発言で「パーを出せば勝てる」ことを伝え、カード選択と勝敗の仕組みを教える。
- チュートリアル完了履歴がないブラウザーでは画面を暗くし、パーのカードだけを前面に表示する。
- パーを選択した時点で完了履歴をブラウザーへ保存し、次回以降は操作オーバーレイを表示しない。
- チュートリアル撃破後は通常敵をランダムに選ぶ。

### 通常敵

- 同じ敵は連続して出現しない。

- グーを出したい男
  - 使用可能: グー∞、チョキ∞
  - 使用不可: パー0
  - グーを出す確率が高い。
- チョキが大好きな女
  - 使用可能: チョキ∞、グー∞
  - 使用不可: パー0
  - チョキを出す確率が高い。
- 手のひら関
  - 使用可能: パー∞、グー∞
  - 使用不可: チョキ0
  - パーを出す確率が高い。

### 強敵

- 敵は撃破に必要な勝利回数をライフとして持ち、敵カード群の中にプレイヤーとは異なる青色のハートで表示する。
- 敵ライフの表示領域は通常敵にも常設し、強敵への切り替えやライフ減少でレイアウトの高さを変えない。

- 嘘松
  - グー、チョキ、パーをすべて無制限に使用できる。
  - 高確率で実際に出す手と異なる手を宣言する。
  - 2回勝利すると撃破。
- 抵抗する男
  - グー、チョキ、パーをすべて無制限に使用できる。
  - グーを出す確率が高い。
  - カードを出す前のヒントはない。
  - 2回勝利すると撃破。

## 敗北後

- あいこまたは敗北によってライフが0になった場合はゲームオーバー。
- ライフが残っている場合は、同じ相手との対戦を続行する。
- ライフが残る敗北は演出後に終了し、同じ相手への次のカード選択へ戻る。
- リトライはゲームオーバー時だけ表示する。チュートリアル中のリトライでは練習相手を初期状態に戻し、チュートリアル後は通常敵と強敵までに必要な通常敵数を再抽選する。
- リトライ時は対戦相手番号と強敵戦の途中勝利数をリセットする。
- ライフが0になった敗北時にも「リトライ」を表示し、初期ライフへ回復して新しい進行を開始できる。
- あいこでライフが0になった場合も結果をバトルフィールドに残し、「リトライ」を表示する。

## 強敵戦

- チュートリアル撃破後、通常敵を3〜5人倒すごとに強敵が出現する。
- 強敵撃破後は通常敵へ戻り、次の強敵までの間隔を再び3〜5人から抽選する。
- 強敵戦では固有の条件が課される。
  - 例: 複数回勝利する必要がある。
- 強敵を撃破すると、カード補充を挟まず次の相手へ進む。

## 未確定事項

- 強敵戦で複数回勝利が必要な場合、途中の敗北・あいこの扱い。
