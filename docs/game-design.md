# ゲーム設計

## 初期状態

- プレイヤーは「グー」「チョキ」「パー」をすべて無制限に使用できる。
- カードは枚数ではなく「使用不可（0）」または「無制限（∞）」で管理する。
- ライフは2から開始し、2つのハートで表示する。
- 0.5ライフは半分塗られたハートで表現する。
- 制限時間は設けない。

## 通常戦

1. プレイヤーと相手がカードを1枚ずつ出す。
2. 両者のカードをオープンし、じゃんけんのルールで勝敗を決める。
3. 結果に応じて以下を処理する。
   - あいこ: ライフを0.5失い、ライフが残っていれば同じ相手との対戦を続ける。
   - 勝利: 次の相手との対戦へ進む。
   - 敗北: ライフを1失う。
- プレイヤーと敵のカードは勝負後も消費されない。

### 勝負演出

1. プレイヤーがカードを選ぶ。
2. プレイヤーのカードと、裏向きの相手カードが場に出る。
3. 相手カードをめくり、両者の手を公開する。
4. 勝利・敗北・あいこを表示する。
5. 演出の完了後に次のターンへ進む。
- 演出中はカードを再選択できない。
- OSでモーション軽減が指定されている場合は、演出時間を短縮する。

## 敵の特徴と発言

- 画面上部に敵の名前、特徴、使用可能なカードを表示する。
- 敵側のカードはプレイヤー側と同じカードUIを使い、並びとアイコンの向きを反転して向かい合わせにする。
- 敵はプレイヤーがカードを選ぶ前に一言発する。
- 発言は次の手のヒントになるが、性格によっては心理戦や嘘を含む。
- 敵のカードも「使用不可（0）」または「無制限（∞）」で管理し、使用しても減らない。

### 最初の相手

- 最初の相手はチュートリアル専用とし、必ずグーだけを出す。
- 特徴と発言で「パーを出せば勝てる」ことを伝え、カード選択と勝敗の仕組みを教える。
- チュートリアル撃破後は通常敵をランダムに選ぶ。

### 通常敵

- グーを出したい男
  - 使用可能: グー∞、チョキ∞
  - 使用不可: パー0
  - グーを出す確率が高い。
- チョキが大好きな女
  - 使用可能: チョキ∞、グー∞
  - 使用不可: パー0
  - チョキを出す確率が高い。
- 手のひら関
  - 使用可能: パー∞、グー∞
  - 使用不可: チョキ0
  - パーを出す確率が高い。

### 強敵

- 嘘松
  - グー、チョキ、パーをすべて無制限に使用できる。
  - 高確率で実際に出す手と異なる手を宣言する。
  - 2回勝利すると撃破。
- 抵抗する男
  - グー、チョキ、パーをすべて無制限に使用できる。
  - グーを出す確率が高い。
  - カードを出す前のヒントはない。
  - 2回勝利すると撃破。

## 敗北後

- あいこまたは敗北によってライフが0になった場合はゲームオーバー。
- ライフが残っている場合は、同じ相手との対戦を続行する。

## 強敵戦

- チュートリアル撃破後、通常敵を3〜5人倒すごとに強敵が出現する。
- 強敵撃破後は通常敵へ戻り、次の強敵までの間隔を再び3〜5人から抽選する。
- 強敵戦では固有の条件が課される。
  - 例: 複数回勝利する必要がある。
- 強敵を撃破すると、カード補充を挟まず次の相手へ進む。

## 未確定事項

- ライフを回復・増加させる手段の有無。
- 強敵戦で複数回勝利が必要な場合、途中の敗北・あいこの扱い。
